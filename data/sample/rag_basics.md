# RAG Basics — Arabic and English Sample Document

## What is RAG?

Retrieval-Augmented Generation (RAG) is an approach that retrieves
relevant information from a knowledge source before generating an answer.

A simple RAG workflow is:

1. Receive a question.
2. Retrieve relevant text.
3. Give the retrieved text to the language model.
4. Generate an answer grounded in that evidence.

## ما هو RAG؟

نظام التوليد المعزز بالاسترجاع (RAG) هو أسلوب يسترجع المعلومات
المرتبطة بالسؤال من قاعدة معرفة قبل إنشاء الإجابة.

التدفق الأساسي لنظام RAG هو:

1. استقبال السؤال.
2. استرجاع النصوص المرتبطة.
3. إرسال المعلومات المسترجعة إلى نموذج اللغة.
4. إنشاء إجابة مبنية على الأدلة المسترجعة.

## Why citations matter

A useful RAG system should make it possible to identify which source
supports an important part of an answer.

## لماذا المصادر مهمة؟

يجب أن يساعد نظام RAG الجيد المستخدم على معرفة المصدر الذي يدعم
المعلومة المهمة في الإجابة.
